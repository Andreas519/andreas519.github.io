# Gemeinsame Teile

Hier liegen später wiederverwendbare und praktisch geprüfte CAD-Bausteine.

Jedes gemeinsame Teil benötigt eine kurze Dokumentation mit:

- Ursprung und Einsatzzweck
- maßgeblichen Parametern und Einheiten
- mechanischen Schnittstellen und Toleranzen
- Autodesk-Fusion-Version
- Projekten, in denen das Teil praktisch geprüft wurde
- verfügbaren Exportformaten
