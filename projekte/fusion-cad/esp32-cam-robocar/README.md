# Schwenkbarer ESP32-CAM-Halter für ein RoboCar

Geplant ist ein parametrischer Frontkamera-Halter mit einstellbarer Neigung.

## Aktueller Stand

Das Projektgerüst ist angelegt. Vor der Konstruktion werden Fotos, Hauptmaße, Lochabstände, gewünschte Kamerahöhe, Neigungsbereich, Befestigungsstelle, Druckverfahren und Toleranzen erfasst.

## Projektordner

- `fusion/`: Fusion-API-Skript und Parameter
- `models/`: Modellquellen und Referenzgeometrie
- `exports/`: STEP, STL und 3MF
- `bilder/`: Fotos, Maßskizzen, Renderings und Probedrucke
