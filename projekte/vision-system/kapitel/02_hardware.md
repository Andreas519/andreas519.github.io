# 2. Hardware

## Verwendete Komponenten

- Raspberry Pi Zero W v1.1
- eingelötete 40-polige GPIO-Stiftleiste
- MicroSD-Karte
- geeignetes 5-V-Netzteil
- Kameramodul mit OV5647-Sensor
- schmales CSI-Kamerakabel für Raspberry Pi Zero

## Wichtige Anschlüsse

- **PWR IN:** Stromversorgung
- **USB:** Datenanschluss
- **Mini-HDMI:** Bildausgabe
- **CSI:** Kameraanschluss
- **GPIO:** Ein- und Ausgänge für Sensoren und Aktoren

## Hinweis zum Kamerakabel

Die Zero-Modelle benötigen auf der Raspberry-Pi-Seite ein schmaleres CSI-Kabel als größere Raspberry-Pi-Modelle.
