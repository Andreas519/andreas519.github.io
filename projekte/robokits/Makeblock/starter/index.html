Makeblock Starter - in Arbeit

Makeblock Starter mit der Arduino IDE programmieren

Der Starter ist das Einsteigerkit für die Programmierung mit der Arduino IDE. Dabei wird das Arduino-Board auf dem Roboter als Entwicklungsumgebung für erste Testprogramme genutzt.

Arduino IDE vorbereiten

In der Arduino IDE muss das richtige Board ausgewählt werden. Für den Starter ist dabei das Board Arduino Uno einzustellen.

Anschließend kann das passende Beispielprogramm über Datei → Beispiele → MakeBlockDrive geöffnet werden. Wenn die Beispielprogramme nicht direkt funktionieren, muss ggf. die Include-Anweisung auf den Orion angepasst werden.

Nicht vorhandene Sensoren oder Aktoren müssen nur dann am Starter angeschlossen werden, wenn sie für den Orion geeignet sind.

Erstes Testprogramm

Das Beispiel blinken.ino kann auf den mBot geladen werden. Danach sollten die beiden Onboard-RGB-LEDs blinken.

Funktioniert das nicht, prüfe zuerst die Vorbereitung der Arduino IDE für Makeblock-Roboterkits.

Hinweise zur Hardware

In den Beispielen der Arduino IDE müssen bei Bedarf die verwendeten Sensoren und Aktoren passend zum Orion des mBot Starter angeschlossen werden. Die Konfiguration der Erweiterungen muss immer zur vorhandenen Hardware passen.
