# Prompt 42 – Prompt und Antwort als Markdown-Dateien

## Prompt

Erstelle für jeden Prompt auf dieser Seite eine Markdown-Datei mit deiner Antwort in einem ZIP-Archiv zum Download.

## Antwort

Dieses Archiv wurde erstellt. Jede Datei enthält:

- den jeweiligen Prompt
- die zugehörige Antwort
- passende Befehle und Codebeispiele

Zusätzlich enthält das Archiv eine Inhaltsübersicht.
