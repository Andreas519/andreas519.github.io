# Prompt 15 – Speicherort der Dokumentation

## Prompt

Der Speicherort der Dokumentation muss festgelegt werden.

## Antwort

Empfohlen wurde ein eigenes Projekt innerhalb der GitHub-Seite:

```text
projekte/
└── raspberry_pi_zero_cam/
```

Vorgeschlagen wurden:

- `README.md`
- `index.html`
- zentrale Markdown-Datei
- einzelne Kapitel
- Bilder
- Python
- Downloads
- Dokumentation

Markdown sollte die Quelle sein, HTML die Webdarstellung und PDF die Druckfassung.
