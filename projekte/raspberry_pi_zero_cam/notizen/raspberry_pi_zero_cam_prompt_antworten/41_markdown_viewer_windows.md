# Prompt 41 – Lokaler Markdown-Viewer unter Windows

## Prompt

Gibt es unter Windows einen lokalen Markdown-Viewer?

## Antwort

Empfohlen wurden:

- Visual Studio Code
- Obsidian
- Typora
- MarkText
- Notepad++

Besonders empfohlen wurde Visual Studio Code.

Markdown-Vorschau:

```text
Strg + Shift + V
```

Vorschau seitlich öffnen:

```text
Strg + K, danach V
```
