# Prompt 16 – Projekt statt Thema

## Prompt

Es handelt sich um ein Projekt und nicht nur um ein Thema wie Raspberry Pi Zero oder Bilderkennung.

## Antwort

Das Projekt wurde als modulares intelligentes Kamerasystem eingeordnet.

Als allgemeine Projektnamen wurden unter anderem vorgeschlagen:

- Intelligentes Kamerasystem
- Vision-System
- YE Vision

Der Vorteil eines allgemeinen Namens: Hardware und Software können später ausgetauscht oder erweitert werden.
