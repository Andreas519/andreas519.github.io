# Prompt 33 – Unauffälliger Zugriff über `index.html`

## Prompt

Der Zugriff auf Markdown-Dateien soll über `index.html` organisiert, aber nicht sehr auffällig sein.

## Antwort

Vorgeschlagen wurden:

- ein aufklappbarer `<details>`-Bereich
- ein dezenter Link im Footer
- eine eigene Seite `projektdateien.html`

Favorisiert wurde ein kleiner Link im Fußbereich, der auf eine geordnete Materialseite führt.
