Raspberry Pi OS 13 (Trixie) ist installiert. Die Kamera `ov5647` wird erkannt. Der Pi ist per RDP und SSH vom Windows-PC erreichbar.

- Die Kamera mit OV5647-Sensor wird korrekt erkannt.
