# Prompt 22 – SCP erfolgreich

## Prompt

Die Datei wurde erfolgreich über die IP-Adresse `192.168.2.128` übertragen.

## Antwort

Der funktionierende Befehl wurde festgehalten:

```powershell
scp pi@192.168.2.128:/home/pi/test.jpg D:\Downloads\
```

Damit war Variante 1 praktisch erfolgreich getestet.
