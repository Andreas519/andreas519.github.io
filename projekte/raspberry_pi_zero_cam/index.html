Raspberry Pi Zero Cam

Kamera-Projekte mit dem Raspberry Pi Zero W und Raspberry Pi Zero 2 W

Projektübersicht

Ein Raspberry Pi Zero mit Kameramodul eignet sich für kompakte Foto-, Zeitraffer- und Beobachtungsprojekte. Der Raspberry Pi Zero 2 W bietet dabei deutlich mehr Leistung als die ursprünglichen Zero-Modelle.

Der Kameraanschluss der Zero-Modelle benötigt ein schmales CSI-Kamerakabel für den Raspberry Pi Zero. Ein gewöhnliches Raspberry-Pi-Kamerakabel ist zu breit.

Benötigte Komponenten

Hardware

  • Raspberry Pi Zero W oder Raspberry Pi Zero 2 W
  • Raspberry-Pi-Kameramodul
  • CSI-Kamerakabel für Raspberry Pi Zero
  • microSD-Karte mit Raspberry Pi OS
  • stabiles 5-V-Netzteil

Software

  • Raspberry Pi OS
  • rpicam-apps für Vorschau, Fotos und Videos
  • Picamera2 für eigene Python-Programme
  • SSH für den Betrieb ohne Monitor

Kamera testen

Nach dem Anschließen und Starten des Raspberry Pi kann die Kamera im Terminal geprüft werden:

rpicam-hello

Ein Foto wird mit folgendem Befehl aufgenommen:

rpicam-still -o testbild.jpg

Für einen Raspberry Pi ohne angeschlossenen Bildschirm eignet sich eine Aufnahme ohne Vorschaufenster:

rpicam-still -n -o testbild.jpg
