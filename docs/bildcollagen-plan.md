# Bildcollagen

## Einheitlicher Standard

- Format: 1672 × 941 Pixel
- Dateityp: PNG
- Querformat
- heller Hintergrund
- dunkelblaue Überschrift
- maximal fünf Themenfelder
- möglichst eigene Geräte verwenden

## Speicherorte

themen/<thema>/bilder/<thema>-quer.png
projekte/<projekt>/bilder/<projekt>-quer.png
