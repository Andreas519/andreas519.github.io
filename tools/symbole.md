## Einfache Textsymbole

Diese Zeichen werden meist unabhängig vom Betriebssystem einheitlich dargestellt.

|---|---|---|

| ✘ | falsch | `&#10008;` |
| ○ | offen | `&#9675;` |
| ● | aktiv | `&#9679;` |
| ◐ | teilweise | `&#9680;` |
| □ | leeres Kästchen | `&#9633;` |
| ■ | gefülltes Kästchen | `&#9632;` |
| ☑ | ausgewählt | `&#9745;` |
| ☒ | abgelehnt | `&#9746;` |
| ★ | Favorit | `&#9733;` |
| ☆ | leerer Stern | `&#9734;` |
| → | weiter | `&#8594;` |
| ← | zurück | `&#8592;` |
| ↑ | nach oben | `&#8593;` |
| ↓ | nach unten | `&#8595;` |
| ↔ | beide Richtungen | `&#8596;` |
| + | hinzufügen | `&#43;` |
| − | entfernen | `&#8722;` |

| ≠ | ungleich | `&#8800;` |

| ≥ | größer oder gleich | `&#8805;` |

## Beispiele

```markdown
## 🛠️ In Arbeit

- ✅ Kamera eingerichtet
- 🧪 Bildübertragung wird getestet
- ⏳ Bildverarbeitung ist geplant
- 💡 Idee: automatische Objekterkennung
- ⚠️ Zugangsdaten nicht veröffentlichen
```

```html
<span class="status" title="In Arbeit" aria-label="In Arbeit">
  &#128736;&#65039;
</span>
```

> Hinweis: Das genaue Aussehen farbiger Symbole kann je nach Betriebssystem, Browser und Schriftart etwas abweichen.
