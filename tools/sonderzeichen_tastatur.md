# Sonderzeichen über die Tastatur eingeben

Am zuverlässigsten verwendest du die **Zeichenübersicht deines Betriebssystems** oder kopierst die Zeichen aus einer Vorlage.

| Zeichen | Bezeichnung | Windows | macOS | Linux-Unicode-Eingabe |
|---|---|---|---|---|
| `→` | Pfeil nach rechts | `Windows` + `.` → Symbole | `Ctrl` + `Cmd` + `Leertaste` | `Ctrl` + `Shift` + `U`, `2192`, `Enter` |
| `←` | Pfeil nach links | `Windows` + `.` → Symbole | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `2190`, `Enter` |
| `↑` | Pfeil nach oben | `Windows` + `.` → Symbole | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `2191`, `Enter` |
| `↓` | Pfeil nach unten | `Windows` + `.` → Symbole | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `2193`, `Enter` |
| `↔` | Doppelpfeil | `Windows` + `.` → Symbole | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `2194`, `Enter` |
| `⇒` | Folgerungspfeil | `Windows` + `.` → Symbole | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `21D2`, `Enter` |
| `#` | Raute / Doppelkreuz | `Shift` + `3` | meist `Option` + `3` | `Shift` + `3` |
| `♦` | Rautenzeichen | `Windows` + `.` → Symbole | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `2666`, `Enter` |
| `·` | mittiger Punkt | `Alt` + `0183`¹ | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `00B7`, `Enter` |
| `•` | Aufzählungspunkt | `Alt` + `0149`¹ | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `2022`, `Enter` |
| `×` | Malzeichen | `Alt` + `0215`¹ | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `00D7`, `Enter` |
| `±` | Plusminuszeichen | `Alt` + `0177`¹ | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `00B1`, `Enter` |
| `≈` | ungefähr gleich | `Windows` + `.` → Symbole | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `2248`, `Enter` |
| `≠` | ungleich | `Windows` + `.` → Symbole | Zeichenübersicht | `Ctrl` + `Shift` + `U`, `2260`, `Enter` |

¹ Bei Windows müssen die Zahlen normalerweise über den **Ziffernblock** eingegeben werden; `Num-Lock` muss aktiviert sein.

## Besonders praktisch unter Windows

Drücke:

```text
Windows-Taste + .
```

Wechsle anschließend im geöffneten Fenster zu **Symbole**. Dort findest du Pfeile, mathematische Zeichen, Satzzeichen und weitere Sonderzeichen.

## Kopiervorlage

```text
←  →  ↑  ↓  ↔  ⇒  ⇐  ⇔

#  ♦  ◊

·  •  ‧

×  ÷  ±  ≠  ≈  ≤  ≥

©  ®  €  °  §
```

## Hinweis zur Raute

Eine Raute kann entweder das Zeichen `#` oder die geometrische Raute `♦` bedeuten. In einer mathematischen oder grafischen Darstellung ist meist `♦` oder `◊` gemeint.
